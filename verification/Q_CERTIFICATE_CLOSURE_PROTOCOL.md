# Q-certificate numerical admission gate

## What is proven and what is not

The 47 archived successful Phase-8 records contain fixed-order opposite-decision witnesses at **Q-1**, supporting a semantic lower bound q* >= Q within the declared finite-target completion model. Phase-2 records `preference_dependence` at **Q**, and Phase-6 repeats the terminal label. Their published identifier/status replay is **not** a recomputation of the sufficient inequality establishing q* <= Q.

Thus **47 conditional matches**, not 47 independently recertified numerical first-resolution points. Never read the numeric status code or `conditional_qstar_Q_matches` as a verified positive-margin inequality.

## Missing inputs for a legitimate unconditional Q certificate

1. Frozen **816 x 14** fold-loss-vector input with task ID, fold ID, method order, score type/direction, known/failure/missing flags, and its own reproducible SHA-256; or a rights-cleared exact-version retrieval procedure that reproduces the same bytes.
2. Original Phase-2 stopping implementation and commit/environment, numerical aggregation/tie policy, and the source for every terminal `Q` stopping condition.
3. For each successful (seed, policy, TV radius, Q, trace digest): complete task/method enclosure inputs and per-candidate defeating rival/weight or conservative support inequality.
4. Precision policy and independently checked outward rounding/error bound for each mean, interval endpoint, rank comparison, weighted support and strict positivity decision.
5. Recomputed **smallest certified positive margin** among all candidates/traces after error allowance (not an unrounded float). Any nonpositive/indeterminate margin must fail closed as NOT CERTIFIED.
6. For the historical 364 archive-completion comparisons, a per-record selection ledger if claiming more than an operation count.

## Required acceptance record

Each certificate row should include the immutable input hash, code commit, seed/policy/radius, Q, trace SHA-256, candidate, rival/weight or certificate data, a lower bound on the relevant gap, a documented aggregate numerical error bound, and a **strictly positive residual lower bound** verified by an independent implementation.

A complete checker must recalculate the inequalities from source arrays rather than copy Phase-2 labels. Certificate means/bounds must refer to the same numeric aggregation target used by the originally frozen experiment. Check all 47 successful traces, not just a representative subset.

Only after these conditions pass may a downstream summary set `independently_recertified_qstar_equals_Q = 47`. Until then it must be `null`, meaning **not assessed**, not zero and not disproof.
